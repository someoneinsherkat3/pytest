# Assert that a certain exception is raised
 اینطوری  فکر کنید `pytest.raises` یعنی: «من **انتظار دارم** این کد خطا بدهد. اگر داد، همه‌چیز درست است. اگر نداد، تست غلط است.»
```python
import pytest

def test_divide_by_zero():
    with pytest.raises(ZeroDivisionError):
        1 / 0
```

- `1 / 0` در پایتون همیشه `ZeroDivisionError` می‌دهد.
- ما گفتیم انتظار همین خطا را داریم.
- پس تست **پاس** می‌شود.

```bash
➜  pytest  -q test_test.py
.                                                                                                        [100%]
1 passed in 0.00s
```

سویچ `q-` همان `quiet--` است و فقط خروجی کوتاه نشان می‌دهد.

```python
import pytest

def test_divide_by_zero():
    with pytest.raises(ZeroDivisionError):
        1 / 2
```

```python
import pytest

def check_age(age):
    if age < 0:
        raise ValueError("age can not be negative")
    return age

def test_negative_age():
    with pytest.raises(ValueError):
        check_age(-5)

def test_valid_age():
    assert check_age(20) == 20
```
