## important hooks

###  `pytest_addoption`

تا الان فقط گزینه‌های آماده pytest (`-v`، `-x`) را داشتیم. با `pytest_addoption` می‌توان **گزینه جدید** را به pytest اضافه کرد.

#### define option

```python
# conftest.py
def pytest_addoption(parser):
    parser.addoption(
        "--runslow",
        action="store_true",
        default=False,
        help="also run slow tests",
    )
```

پارامتر `parser` را pytest می‌دهد. `parser.addoption` شبیه `argparse` پایتون است . مهم‌ترین آرگومان‌ها:

| آرگومان               | معنی                                                               |
| --------------------- | ------------------------------------------------------------------ |
| اولین مقدار           | نام گزینه، مثل `"runslow--"`                                       |
| `action="store_true"` | گزینه مقدار نمی‌گیرد؛ اگر مقدار بدهیم `True` می‌شود،نزاریم `False` |
| `action="store"`      | گزینه یک مقدار می‌گیرد، مثل `env=prod--`                           |
| `default`             | مقدار وقتی گزینه داده نشود                                         |
| `help`                | متنی که در `pytest --help` دیده می‌شود                             |
| `type`                | نوع مقدار، مثل `int`                                               |

بعد از تعریف، در `pytest --help` گزینه‌ را در بخش «custom options» نشان میدهد.

#### read options value 

هر hookای که ارگمان `config` را دارد  با عبارت `config.getoption` میتوانیم مقدارش را بخوانیم:

```python
config.getoption("--runslow")      # True or False
```

```python
def pytest_configure(config):
	print(config.getoption("--runslow"))

```

#### connect to  `pytest_collection_modifyitems`

```python
# conftest.py
import pytest

def pytest_addoption(parser):
    parser.addoption("--runslow", action="store_true", default=False,
                      help="also run slow tests",)

def pytest_configure(config):
    config.addinivalue_line("markers", "slow: slow tests ")

def pytest_collection_modifyitems(config, items):
    if config.getoption("--runslow"):
        return                                    
    skip_slow = pytest.mark.skip(reason="use --runslow to run ")
    for item in items:
        if "slow" in item.keywords:
            item.add_marker(skip_slow)
```

توضیح سه hook:

1. ‏`pytest_addoption`: گزینه را تعریف می‌کند.
2. ‏`pytest_configure`: marker `slow` را ثبت می‌کند تا هشدار ندهد.
3. ‏`pytest_collection_modifyitems`: اگر گزینه داده نشده باشد، تست‌های دارای marker `slow` را رد می‌کند.

#### tests

```python
# test_a.py
import pytest

def test_fast():
    assert True

@pytest.mark.slow
def test_slow():
    assert True
```

```bash
pytest -rs              # رد می‌شود test_slow 
pytest --runslow        # هر دو اجرا می‌شوند
```

انتظار خروجی بار اول: `1 passed, 1 skipped` و بار دوم: `2 passed`.

#### option that give value

```python
def pytest_addoption(parser):
    parser.addoption("--env", action="store", default="dev",
                     help="run environments : dev or prod")
```

برای اینکه تست‌ها به مقدار دسترسی داشته باشند، یک fixture می‌سازیم (اینجا fixture و hook با هم کار می‌کنند):

```python
import pytest

@pytest.fixture
def env(request):
    return request.config.getoption("--env")
```

```python
def test_env(env):
    print("environmets: ", env)
```

```bash
pytest -s --env=prod
```

‏`request.config` همان `config` است؛ fixture با `request` به آن می‌رسد.

## tips

1. **جای `pytest_addoption`:** باید در `conftest.py` **ریشه** (یا پلاگین) باشد. در `conftest.py` یک زیرپوشه گاهی دیر بارگذاری می‌شود و گزینه شناخته نمی‌شود. دلیل: این hook خیلی زود صدا زده می‌شود، قبل از اینکه pytest وارد پوشه‌های داخلی شود.
2. **نام گزینه:** با `--` شروع می‌شود. می‌توانی نام کوتاه هم داد: `parser.addoption("-E", "--env", ...)`.
