# خلاصه hookهای مهمی که هنوز بررسی نکردیم

## نتیجه تست‌ها

| hook                                            | کاربرد                                                                                                            |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `pytest_runtest_makereport(item, call)`         | ساخت گزارش هر مرحله (setup، call، teardown). برای فهمیدن فیل شدن تست و گرفتن اطلاعاتش (معمولاً با `hookwrapper`). |
| `pytest_runtest_logreport(report)`              | وقتی گزارش یک مرحله آماده شد صدا زده می‌شود. برای ثبت نتیجه در فایل یا سیستم دیگر                                 |
| `pytest_exception_interact(node, call, report)` | وقتی تستی با خطا تمام شد (مثلاً برای ورود به debugger)                                                            |

## اجرای هر تست

|hook|کاربرد|
|---|---|
|`pytest_runtest_setup(item)`|قبل از هر تست؛ مثلاً رد کردن تست با `pytest.skip` بر اساس شرط|
|`pytest_runtest_call(item)`|خود اجرای تست (معمولاً دورش `wrapper` می‌پیچند، مثلاً برای زمان‌سنجی)|
|`pytest_runtest_teardown(item)`|بعد از هر تست|
|`pytest_runtest_protocol(item)`|کل چرخه یک تست؛ خیلی پیشرفته|

## جمع‌آوری تست‌ها

| hook                                             | کاربرد                                                      |
| ------------------------------------------------ | ----------------------------------------------------------- |
| `pytest_generate_tests(metafunc)`                | parametrize پویا؛ ساختن پارامترها موقع اجرا (مثلاً از فایل) |
| `pytest_ignore_collect(collection_path, config)` | نادیده گرفتن یک مسیر                                        |
| `pytest_collect_file(file_path, parent)`         | تعریف فایل‌های تست با فرمت دلخواه (مثلاً `yaml.`)           |
| `pytest_collection_finish(session)`              | بعد از پایان جمع‌آوری                                       |
| `pytest_deselected(items)`                       | وقتی تست‌هایی با `k-` یا `m-` کنار گذاشته شدند              |

## fixture

|hook|کاربرد|
|---|---|
|`pytest_fixture_setup(fixturedef, request)`|موقع ساخت هر fixture|
|`pytest_fixture_post_finalizer`|بعد از پاک‌سازی fixture|

## گزارش و خروجی ترمینال

|hook|کاربرد|
|---|---|
|`pytest_report_header(config)`|خطی که بالای گزارش چاپ می‌شود|
|`pytest_terminal_summary(terminalreporter)`|متن اضافه در پایان گزارش|
|`pytest_report_teststatus(report)`|تغییر حرف یا رنگ نمایش وضعیت (مثلاً `.` و `F`)|
|`pytest_assertrepr_compare(op, left, right)`|پیام سفارشی برای `assert` روی نوع دلخواه|

## تنظیمات و پلاگین

|hook|کاربرد|
|---|---|
|`pytest_unconfigure(config)`|پایان کار، مقابل `pytest_configure`|
|`pytest_load_initial_conftests`|خیلی زود، قبل از بارگذاری conftestها (پیشرفته)|
|`pytest_plugin_registered`|وقتی پلاگینی ثبت شد|
