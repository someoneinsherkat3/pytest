# تست برنامه‌های ++C و لینوکس با pytest

‏ pytest کد پایتون اجرا می‌کند، و پایتون می‌تواند **هر برنامه‌ای را اجرا کند و خروجی و کد خروجش را چک کند**. ابزار اصلی کار `subprocess` است.

## `subprocess.run`

```python
import subprocess

r = subprocess.run(["echo", "hello"], capture_output=True, text=True)
print(r.stdout)       # "hello\n"
print(r.stderr)       # خروجی خطا
print(r.returncode)   # 0
```

| بخش                   | معنی                                    |
| --------------------- | --------------------------------------- |
| لیست اول              | دستور و آرگومان‌ها، هر کدام یک عضو لیست |
| `capture_output=True` | ‏`stdout` و `stderr` را بگیر            |
| `text=True`           | خروجی را `str` بده نه `bytes`           |
| `input="..."`         | چیزی که به `stdin` برنامه داده می‌شود   |
| `timeout=5`           | اگر بیشتر از ۵ ثانیه طول کشید، خطا بده  |
| `check=True`          | اگر کد خروج غیر صفر بود، استثنا بده     |

## test Linux App 

```python
import subprocess

def run(*cmd):
    return subprocess.run(cmd, capture_output=True, text=True, timeout=10)

def test_echo():
    r = run("echo", "hello")
    assert r.returncode == 0
    assert r.stdout == "hello\n"

def test_ls_missing_file():
    r = run("ls", "/nonexistent")
    assert r.returncode != 0
    assert "No such file" in r.stderr

def test_wc_with_stdin():
    r = subprocess.run(["wc", "-l"], input="a\nb\nc\n", capture_output=True, text=True)
    assert r.stdout.strip() == "3"
```

با `tmp_path` فایل واقعی بساز:

```python
def test_cat(tmp_path):
    f = tmp_path / "a.txt"
    f.write_text("hi\n")
    r = run("cat", str(f))
    assert r.stdout == "hi\n"
```

```cpp
// add.cpp
#include <iostream>
#include <string>

int main(int argc, char* argv[]) {
    if (argc != 3) {
        std::cerr << "usage: add A B\n";
        return 1;
    }
    std::cout << std::stoi(argv[1]) + std::stoi(argv[2]) << "\n";
    return 0;

```

### use fixture for compile 

برنامه را **یک‌بار برای کل تست‌ها** کامپایل می‌کنیم. این دقیقاً کاربرد `"scope="session` و `tmp_path_factory` است که گفته شد:

```python
import subprocess
import pytest

@pytest.fixture(scope="session")
def add_exe(tmp_path_factory):
    exe = tmp_path_factory.mktemp("build") / "add"
    subprocess.run(["g++", "add.cpp", "-o", str(exe)], check=True)
    return str(exe)
```

### tests

```python
def run_exe(exe, *args, **kw):
    return subprocess.run([exe, *args], capture_output=True, text=True, timeout=5, **kw)

def test_add(add_exe):
    r = run_exe(add_exe, "2", "3")
    assert r.returncode == 0
    assert r.stdout == "5\n"

def test_no_args(add_exe):
    r = run_exe(add_exe)
    assert r.returncode == 1
    assert "usage" in r.stderr
```

### with parametrize

```python
@pytest.mark.parametrize("a, b, expected", [
    ("2", "3", "5"),
    ("0", "0", "0"),
    ("-1", "-1", "-2"),
    ("100", "-100", "0"),
])
def test_add_many(add_exe, a, b, expected):
    assert run_exe(add_exe, a, b).stdout.strip() == expected
```

## tips


‏ **crash و سیگنال:** اگر برنامه با segfault بمیرد، `returncode` منفی است (منفی شماره سیگنال):

```python
def test_no_crash(add_exe):
    r = run_exe(add_exe, "1", "2")
    assert r.returncode >= 0        # منفی یعنی با سیگنال کشته شده، مثلاً -11 یعنی SIGSEGV
```

‏ **timeout:** برنامه‌ای که در حلقه بی‌نهایت می‌افتد تست را قفل نمی‌کند، چون `subprocess.TimeoutExpired` می‌دهد:

```python
def test_hangs(add_exe):
    with pytest.raises(subprocess.TimeoutExpired):
        subprocess.run(["sleep", "10"], timeout=1)
```

**متغیر محیطی و پوشه جاری:**

```python
def test_env(tmp_path):
    r = subprocess.run(["sh", "-c", "echo $MYVAR"], capture_output=True, text=True,
                       env={"MYVAR": "x", "PATH": "/usr/bin:/bin"}, cwd=tmp_path)
    assert r.stdout == "x\n"
```

**هرگز** `shell=True` را با ورودی‌های ناشناخته استفاده نکنید، حتما لیست آرگومان بدهید  نه صرفا رشته.

## test project struct 

```
project/

├── src/
│   └── add.cpp
└── tests/
    ├── conftest.py     ← fixture کامپایل
    └── test_add.py
```

در `conftest.py` مسیر مطلق میدهیم تا از هر پوشه‌ای اجرا شود:

```python
import subprocess
from pathlib import Path
import pytest

SRC = Path(__file__).parent.parent / "src"

@pytest.fixture(scope="session")
def add_exe(tmp_path_factory):
    exe = tmp_path_factory.mktemp("build") / "add"
    subprocess.run(["g++", str(SRC / "add.cpp"), "-o", str(exe)], check=True)
    return str(exe)
```

## `.deb` packages

```python
def test_deb_content():
    r = subprocess.run(["dpkg", "-c", "mypkg.deb"], capture_output=True, text=True)
    assert r.returncode == 0
    assert "./usr/bin/myprog" in r.stdout

def test_deb_info():
    r = subprocess.run(["dpkg", "-I", "mypkg.deb"], capture_output=True, text=True)
    assert "Package: mypkg" in r.stdout
```
