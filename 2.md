# parametrize
فرض کنید یک تابع را با چند ورودی مختلف تست می‌کنیم:
```python
def add(a, b):
    return a + b

def test_add_1():
    assert add(1, 2) == 3

def test_add_2():
    assert add(2, 3) == 5

def test_add_3():
    assert add(0, 0) == 0
```

سه تابع تقریباً یکسان نوشتیم و فقط عددها فرق دارند. نوشتن چندباره بیخود است . راه‌حل استفاده از  `pytest.mark.parametrize@` است 

```python
import pytest

def add(a, b):
    return a + b

@pytest.mark.parametrize("a, b, expected", [
    (1, 2, 3),
    (2, 3, 5),
    (0, 0, 0),
])
def test_add(a, b, expected):
    assert add(a, b) == expected
```

اینجا یک تابع تست نوشتیم، ولی pytest آن را **سه بار** اجرا می‌کند، هر بار با یک ردیف از لیست.



- **آرگومان اول**: یک **رشته** با نام پارامترها، جدا شده با کاما: `"a, b, expected"`.
- **آرگومان دوم**: لیستی از ردیف‌ها. هر ردیف یک تاپل است و مقدارها به ترتیب به `a` و `b` و `expected` داده می‌شوند.
- نام این پارامترها باید **دقیقاً** با پارامترهای تابع تست یکی باشد.

```python
@pytest.mark.parametrize("a, b, expected", [...])
@pytest.mark.parametrize("arg1, arg1, result", [...])
@pytest.mark.parametrize("arg1, arg1, return", [...])
```


میتوان هر دریف از وردی ها را هم  نام‌گذاری کرد با **ارگمان سوم** `ids` 

```python
@pytest.mark.parametrize(
    "a, b, expected",
    [
        (1, 2, 3),
        (-1, -1, -2),
        (0, 0, 0),
    ],
    ids=["positive", "negative", "zero"],
)
def test_add(a, b, expected):
    assert add(a, b) == expected
```

## میتوان  Parametrize با خطا داشت
```python
@pytest.mark.parametrize("bad_value", ["abc", None, [], {}])
def test_int_conversion_fails(bad_value):
    with pytest.raises((ValueError, TypeError)):
        int(bad_value)
```
